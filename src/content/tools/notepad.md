## When to use it

Use this online notepad for quick notes that you want to keep without signing in anywhere: phone numbers during a call, a shopping list, meeting notes, a draft email, or code snippets. It saves as you type, keeps several notes, and works offline once loaded.

## How to use it

1. Start typing in **Note**. The note saves itself, and the status changes from "Saving…" to "✓ Saved on this device".
2. Click **New note** to start another. Use **Choose a note** to switch between them.
3. Use **Save .txt** to download the current note, or **Open file** to load a text file.
4. Click **Copy** to copy all the text.
5. Tick **Monospace** for code or tables, and change the **Text size** to suit your eyes.
6. Press **Focus** for a distraction-free full-screen view.
7. **Delete** removes the current note after asking you to confirm.

The bar under the note shows the number of words, characters and lines.

## Worked example

During a phone call with a plumber, open the notepad and type "Plumber call" on the first line, then the date, price and arrival time. The note appears in the list as "Plumber call". Later you start a new note for a shopping list. Both are there the next time you open the page in the same browser.

Before switching to a new laptop, open each note and press **Save .txt** to keep a copy, then use **Open file** on the new laptop.

## Several notes, one page

The list keeps your most recently edited notes at hand, so you can use one note for a running to-do list, another for ideas and another for work. Switching notes is instant, and each one keeps its own text exactly as you left it.

## Tips

- **Give every note a first-line title.** It makes the list easy to scan.
- **Use Monospace for code.** Characters line up, and spaces are easier to see.
- **Back up anything important.** Browser storage is convenient, but a downloaded file is safer.
- **Paste plain text here first.** Copying formatted text from a web page into the notepad and back out removes unwanted fonts and colors.

## Common mistakes

- **Writing in a private window.** Notes disappear when the window closes.
- **Expecting notes on another device.** They live only in this browser on this device.
- **Keeping passwords here.** Notes are stored as plain text in the browser. Use a password manager instead.
