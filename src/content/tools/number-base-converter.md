## What this converter does

The number base converter translates numbers between decimal (base 10), binary (base 2), hexadecimal (base 16), octal (base 8) and any other base from 2 to 36. Type in any box and all the others update instantly. The binary value is also shown grouped into bytes, with the number of bits it needs.

## How to use it

1. Type a number in the **Decimal**, **Binary**, **Hexadecimal** or **Octal** box.
2. The other boxes fill in automatically.
3. Change **Other base** to convert to an unusual base such as base 36.
4. Press **Copy** next to any value.

- 0xFFFF = 65,535 decimal

## Understanding number bases

- **Decimal** uses ten digits (0 to 9) because humans count on ten fingers.
- **Binary** uses two digits because computers store information as on and off.
- **Hexadecimal** uses sixteen digits (0 to 9 and A to F) and maps neatly onto groups of four bits.
- **Octal** uses eight digits and appears in Unix file permissions, such as 755.
