## When to use it

The character counter shows exactly how long your text is, with live bars for common limits: X posts, Instagram and TikTok captions, LinkedIn posts, YouTube titles, SMS messages, SEO page titles and meta descriptions. Use it before posting, while writing ad copy and product descriptions, filling in forms with a character limit, or writing text for apps and buttons where space is tight.

## How to count characters

1. Type or paste into **Your text**. Everything updates as you type.
2. Check **Common character limits**. Each bar shows your count against a limit, such as "X / Twitter post 0 / 280" or "Meta description 0 / 160", and turns red when you go over.
3. See the full breakdown: **Characters**, **Without spaces**, **Letters**, **Words**, **Sentences**, **Lines** and **Bytes (UTF-8)**.
4. Use **Copy text** to copy it back out, or **Clear** to start again.

## A worked example

You're writing a meta description for a bakery's website and want it to show in full in Google. You type: "Fresh sourdough, pastries and custom cakes baked daily in Leeds. Order online for same-day collection, or visit our café on Market Street." The meta description bar shows 138 / 160, so it fits. The page title bar warns that your 68-character title is over 60, so you shorten it before publishing.

## Popular limits

- **X post:** 280 characters (links count as 23).
- **Instagram and TikTok captions:** 2,200, but only about 125 show before "more".
- **SMS:** 160 plain characters per message.
- **Meta description:** about 155 to 160 characters before Google cuts it off.
- **Page title (SEO):** about 50 to 60 characters.
- **YouTube title:** 100 characters, with about 70 visible in search.

## Tips

- **Front-load the important words;** many platforms truncate long text.
- **Watch the "more" cut-off** on social captions, not just the maximum.
- **Count bytes** when an API or database rejects text that looks short enough.
- **Leave a little room** under strict limits, in case a platform counts slightly differently.

## Common mistakes

- **Counting words when the limit is characters,** or the reverse.
- **Forgetting spaces and punctuation,** which almost always count.
- **Assuming every platform counts emoji the same way.**
