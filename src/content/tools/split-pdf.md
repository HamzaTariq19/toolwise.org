## What this tool does

Split PDF breaks one PDF document into several smaller ones. Use it to separate a scanned stack of documents, send only the relevant chapter of a long report, split a large file to get under an email attachment limit, or save each page of a statement as its own file.

## How to split a PDF

1. Tap **Choose PDF file** or drag a PDF onto the box.
2. Choose how to split it:
   - **Custom ranges:** type the page ranges you want, such as `1-3, 4-6, 7`.
   - **Every page:** each page becomes a separate PDF.
   - **Every N pages:** for example, every 2 pages for double-sided forms.
3. Press **Split PDF**.
4. Download each file individually, or press **Download all (ZIP)** to get them all at once.

## Writing page ranges

- `1-5` gives one file with pages 1 to 5.
- `1, 2, 3` gives three files with one page each.
- `1-2, 3-10, 11-end` gives three files, the last one running to the end of the document.

If you type a page that does not exist, toolwise tells you how many pages the PDF has so you can correct it.

## Useful tips

- **Scanned a pile of documents in one go?** Use Every N pages if every document has the same number of pages, otherwise use custom ranges.
- **Only want to remove a few pages?** [Delete PDF Pages](/delete-pdf-pages) is quicker.
- **Want to combine pieces again later?** Use [Merge PDF](/merge-pdf) to join them in any order.
- **File names** include the page numbers, for example `report-pages-4-6.pdf`, so you always know which part is which.

## Private by design

Your PDF never leaves your device: it is opened, split and saved entirely within your browser. That makes it safe for bank statements, contracts, medical records and anything else you would rather not upload to a stranger's server.
