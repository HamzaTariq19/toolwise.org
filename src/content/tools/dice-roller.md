## When to use it

Use this dice roller for board games when the dice are lost, tabletop role-playing games like Dungeons & Dragons, classroom probability lessons, or any time you need a random number in a fair, familiar way. It handles everything from a single d6 to complex rolls with modifiers.

## How to use it

1. Choose the **Dice type**: d4, d6, d8, d10, d12, d20 or d100.
2. Set **How many** with − and +.
3. Or type a roll in **Or type dice notation**, such as 3d6, d20+5 or 2d8+1d4−1.
4. Press **Roll dice**.
5. Read the **Total** and the breakdown of each die. Earlier results appear under **Recent rolls**. Press **Clear** to empty the list.

## Worked example

In a role-playing game, your character attacks with a +5 bonus. Type d20+5 and press **Roll dice**. The die shows 11, so the total is 16, shown as 1d20 (11) + 5. If the enemy's armour class is 15, the attack hits.

The attack then does damage of 2d6+3. Type that and roll: perhaps 4 and 6 for 10, plus 3, for 13 damage. **Recent rolls** keeps both results, so the group can check them.

For a board game that needs two normal dice, leave the default of 2d6 and press **Roll dice** each turn.

## Probability with dice

- With one d6, each number has a 1 in 6 chance.
- With 2d6, totals are not equally likely. 7 is the most common, with 6 ways to make it out of 36, while 2 and 12 have only 1 way each.
- With more dice, totals cluster more tightly around the middle.

Roll 2d6 many times in class and tally the totals to see this pattern appear.

## Tips

- **Write rolls in notation.** It is quicker than changing the dice type and count each time.
- **Use Recent rolls to settle disputes.** Everyone can see the result and the breakdown.
- **Use the right die for the rule.** Many games use d20 for checks and smaller dice for damage.
- **Keep it on a tablet in the middle of the table.** Everyone can tap to roll and see the result.

## Keyboard and screen readers

The Roll dice button works with Enter, and each result is announced, so the roller is easy to use without a mouse.

## Common mistakes

- **Typing the modifier in the wrong place.** Use d20+5, not 5+d20, for clarity, although both work the same.
- **Confusing 2d6 with d12.** Both go up to 12, but 2d6 gives middle totals much more often.
