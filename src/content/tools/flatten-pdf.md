## What this tool does

Flatten PDF merges the editable parts of a PDF into the page itself. After flattening, filled-in form fields, comments, highlights and stamps look exactly the same but cannot be changed. This is useful before sending a completed form, archiving a signed agreement, or sharing a document that should look identical in every PDF reader.

## How to flatten a PDF

1. Tap **Choose PDF file** and select your PDF.
2. toolwise tells you how many form fields it found.
3. Choose **Form fields** or **Everything**.
4. Press **Flatten PDF** and download the result.

## The two modes explained

- **Form fields** converts each field's current value into regular page content and removes the field. Text stays crisp, selectable and searchable, and the file size barely changes. This is the best choice for completed application forms, tax forms and questionnaires.
- **Everything** draws each page as an image, including all annotations, comments and stamps. Nothing can be edited afterwards, and the document looks identical in every viewer. Text can no longer be selected, so use it only when you need everything locked.

## When to flatten

- **Submitting forms:** some offices ask for flattened forms so answers cannot be altered and display correctly in their systems.
- **Fixing display problems:** if your answers disappear or look different in another app, flattening fixes them in place.
- **Archiving:** a flattened copy of a signed or approved document is a stable record.
- **Printing:** some printers skip form fields or comments; flattened pages print exactly as they appear on screen.

## Checking the result

Open the flattened PDF and try clicking on a field you filled in: it should no longer be editable, and your answer should still be visible exactly where you typed it. If you chose Everything, also try selecting a word; it will select as part of an image instead of as text. That confirms the page is fully locked.

## Private

Flattening runs in your browser. Your PDF is never uploaded or stored.
