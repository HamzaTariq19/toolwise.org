## When to use it

The case converter changes the capitalisation of text in one click. Use it to fix text typed with Caps Lock on, turn shouting ALL-CAPS emails into normal sentences, format headings and titles consistently, prepare product names or data for a spreadsheet, or create variable names, file names and URL slugs for code and websites.

## How to change text case

1. Paste or type into **Your text**, or press **Example** to see how it works.
2. Under **Convert to**, choose a style:
   - **Sentence case**, **lowercase**, **UPPERCASE**
   - **Title Case** (headline style) or **Capitalize Each Word**
   - **aLtErNaTiNg** and **iNVERSE** for fun
   - **camelCase**, **snake_case** or **kebab-case** for code and URLs
3. Read the **Result**, then press **Copy result** or **Download .txt**.
4. Press **Clear** to start again.

## A worked example

A colleague sends a list of blog post titles typed in all capitals: "HOW TO PLAN A WEEKEND IN THE LAKE DISTRICT". Choose **Title Case** and it becomes "How to Plan a Weekend in the Lake District", with "to", "a" and "in" correctly in lowercase. For the page's web address, switch to **kebab-case**: "how-to-plan-a-weekend-in-the-lake-district".

## Which style to use

- **Sentence case:** body text, buttons, most UK and modern web headings.
- **Title Case:** book, film and article titles; many US-style headlines.
- **UPPERCASE:** short labels, warnings and acronyms; avoid for long text.
- **lowercase:** email addresses, tags and some brand styles.
- **camelCase / snake_case / kebab-case:** code, database fields, file names and URLs.

## Tips

- **Check proper nouns** (names, places, brands) after using Sentence case.
- **Fix acronyms** like NASA or UK if a style lowercases them.
- **Pick one style for headings** across a document or website and stick to it.
- **Each line is handled separately,** so lists of titles convert in one go.

## Programming styles at a glance

From "Order total amount": camelCase gives `orderTotalAmount`, snake_case gives `order_total_amount`, and kebab-case gives `order-total-amount`.

## Common mistakes

- **Using UPPERCASE for whole paragraphs,** which reads like shouting and is harder to read.
- **Expecting the tool to know names.** "london bridge" won't become "London Bridge" in sentence case.
- **Using spaces in code names;** use camelCase, snake_case or kebab-case instead.
