## When to use it

Use this tool to turn audio files into MP3, the format that plays on almost every phone, car stereo, computer and app. It is useful for voice memos saved as M4A, recordings from a field recorder in WAV, FLAC music for an older player, or audio from a WebM file that will not open on your device.

## How to use it

1. Choose the **Quality**: 128 kbps (smaller files, speech), 192 kbps (recommended), 256 kbps or 320 kbps (best quality).
2. Choose the **Channels**: **Keep stereo or mono**, or **Mono (half the size)**.
3. Click to choose files, or drop them onto the box. WAV, M4A, AAC, OGG, FLAC, WebM, MP4 and more work, up to 100 MB each.
4. The conversion starts right away. A progress bar shows each file in turn.
5. Download each MP3, or use **Download all (ZIP)** when you converted several.

Set the quality and channels before adding files, because they apply as each file is converted. If one file fails, for example because it is damaged, the others still convert and the problem file shows a short message.

## Worked example

You have a 4-minute song saved as a WAV file of about 40 MB. Converting it at 192 kbps gives an MP3 of about 5.8 MB, roughly a seventh of the size, and it still sounds great in headphones.

You also have a folder of 20 voice memos in M4A format from a meeting. Choose 128 kbps and **Mono**, then drop all 20 files at once. Each MP3 is small, and you can download them together as one ZIP file.

## Tips

- **Convert from the best copy you have.** A WAV or FLAC file gives a better MP3 than a low-quality M4A.
- **Use mono for voices.** It halves the size with no real loss for speech.
- **Keep the originals.** MP3 throws away some detail, so keep the lossless files if you might edit them later.
- **Check names in the ZIP.** If two files share a name, such as song.wav and song.flac, the format is added to keep them apart.

## Common mistakes

- **Choosing 320 kbps for low-quality sources.** It makes the file bigger without making it sound better.
- **Converting video files.** You can convert a video's sound here, but [Extract Audio](/extract-audio) handles large video files better.
- **Using mono for music.** Stereo music loses its sense of space when mixed to mono.
